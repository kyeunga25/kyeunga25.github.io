- **Containerization:** All services managed via **Docker Compose**.
- **Networking:** Secured via **Nginx Reverse Proxy**, DDNS and automated SSL. (Later changed to Cloudflare Tunnel)
- **Application:** **Self-host** different open-source projects like password manager Vaultgarden, media server jellyfin etc.
